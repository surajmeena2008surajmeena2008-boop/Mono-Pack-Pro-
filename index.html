How to use

Four taps. One file.

No install, no account, no uploads. Everything happens inside your browser.

01
Get your zip ready

Use a built website (index.html with its CSS, JS, images) or a React/Vite source project. A dist or build folder zip is the safest.

02
Drop or pick the zip

Drag it onto the box, or tap it and choose the file from your phone or computer.

03
Watch it pack

The app finds your entry page, inlines CSS, scripts, images and fonts, and compiles React/TypeScript when needed.

04
Preview and download

Check the live preview, then tap Download HTML. Open the file in any browser or share it.

Add to home screen. Android Chrome: menu, then Install app. iPhone/iPad Safari: Share, then Add to Home Screen. Desktop Chrome/Edge: install icon in the address bar. Normal zips then work even offline.
Best results. Keep the internet on for React/TypeScript projects (libraries load from a CDN). Compress very large photos first. Test the downloaded file once before sharing.
Guidelines & limits

What works. What can’t.

One HTML file is a browser page, not a server. These are the honest boundaries.

Static site (HTML, CSS, JS)Works fully, even offline
Built folder (dist / build)Works fully, even offline
React + Vite (TS or JS)Works, needs internet to open the result
Plain JS modules (import/export)Works, may need internet
Images and files loaded by JSEmbedded up to about 24 MB total
Multi-page sitesOnly the main page is packed
Vue, SvelteNot supported yet
Next.js, Angular, server renderingNot supported
Backend (Node, Python, database, login)Cannot run inside one HTML file
Size. Images become base64 and grow about 33%. Very large zips can be slow on phones because everything runs in your device’s memory. Under about 50 MB is comfortable.
Rules

Use it well.

Do

  • Convert only projects you own or have permission to use.
  • Put index.html at the top of the zip or inside dist/build.
  • Compress huge images and videos first.
  • Keep internet on for React/TypeScript projects.
  • Open and test the downloaded file before publishing.

Don’t

  • Don’t include passwords, API keys or private data. They get embedded and stay readable inside the HTML.
  • Don’t convert malware, stolen work or anything illegal.
  • Don’t expect servers, databases or logins to work.
  • Don’t rely on it for legal, medical or financial documents without checking the output.
Terms & privacy

Plain and short.

Privacy
  • Your zip is read and converted on your device. It is never uploaded to our servers, and there are no accounts or analytics.
  • The page loads helper libraries from public CDNs (Google Fonts, cdnjs, jsDelivr, esm.sh). Those providers can see your IP address and follow their own policies.

FAQ

Quick answers.

My preview is blank. Why?

Usually the zip is a source project the tool could not compile, or a script crashed. Check the log under the buttons, then try the downloaded file in a normal browser tab.

Is my zip uploaded anywhere?

No. Conversion runs locally in your browser.

Why does the React result need internet?

React and other libraries are loaded from a CDN each time the file opens. A built dist folder produces a fully offline file instead.

Does it work on iPhone and iPad?

Yes, in Safari 15 or newer. Use Share, then Add to Home Screen to install it.

Why is the HTML so big?

Embedded images and fonts are base64, which adds about 33%. Compress images before zipping.

Can I host the output?

Yes. It is a normal HTML file. Upload it to GitHub Pages, Netlify or any static host.
